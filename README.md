# SPFRIME: multi-source 2D DOA estimation

This repository contains the reference implementation and paper-level reproduction code for **SPFRIME**, a selective projected-subspace fusion RIME method for multi-source two-dimensional direction-of-arrival (DOA) estimation with a uniform circular array (UCA).

SPFRIME combines rank-truncated recursive projected-subspace initialization, recursion-aware selective subgrid fusion with exact projected-subspace rescoring, cyclic conditional deterministic maximum-likelihood (DML) refinement driven by RIME, and bounded joint-DML refinement.

## Repository scope

This is the publication repository for the proposed method. It contains the self-contained SPFRIME implementation, the paper-level array and experiment settings, reproducibility runners for the principal experiments, and regression/smoke tests. Development prototypes, virtual environments, IDE metadata, and large generated Monte Carlo result folders are excluded.

The manuscript states the scientifically material experimental settings. Lower-level simulation-generation constants are kept in the code so that they do not unnecessarily expand the paper.

## SPFRIME implementation

The self-contained reference implementation is `spfrime.py`.

```python
from spfrime import trap_dml_rime

azimuth, elevation = trap_dml_rime(
    X,
    array_pos,
    wavelength,
    theta_grid,
    phi_grid,
    k_sources,
    evidence_step=2.5,
    conditional_budget=896,
    seed=0,
)
```

The source count is assumed known, consistent with the manuscript.

## Paper configuration

`experiments/paper_protocol.py` collects the paper-level settings. The principal configuration uses:

- a 12-element horizontal UCA with adjacent chord length `lambda/2` (`r/lambda ≈ 0.965926`);
- azimuth `0–360 deg` and elevation `0–90 deg`;
- projected-evidence step `h = 2.5 deg`;
- conditional-DML RIME budget `B = 896` per coordinate update;
- two cyclic conditional-DML sweeps;
- the same `h` as the half-width of the final bounded joint-DML refinement;
- 500 paired Monte Carlo trials for the reported statistical experiments.

## Reproduce the principal experiments

Run from the repository root.

Main SNR experiment:

```bash
python -m experiments.run_spfrime_paper --experiment main-snr --trials 500
```

Exact spherical two-source resolution experiment:

```bash
python -m experiments.run_spfrime_paper --experiment resolution --trials 500
```

Both:

```bash
python -m experiments.run_spfrime_paper --experiment all --trials 500
```

Generated CSV files are written to `results/public_reproduction/` by default. All observations are generated by the scripts; no external dataset is required.

## Tests

```bash
python -m pytest -q
```

The protocol tests include a check that the 12-element UCA has adjacent chord length `lambda/2`.

## Reproducibility note

Objective-evaluation counts from heterogeneous estimators are not equal-cost operations. The manuscript therefore uses measured wall-clock time as the primary implementation-level efficiency measure and reports evaluation counts as an auxiliary workload indicator.
